Visible day
Default window is 9:00 → 22:00 (13 hours).
Any block or calendar event outside it widens the window automatically (start floors to the hour, end ceils to the half hour).
Earlier reveals 2 hours per click, down to 1:00. Later reveals up to 23:30. The − rows put it back.
Hour height = available height ÷ visible hours. The grid never scrolls.
Voice
Short, warm, plain. Verbs first: “Drag an activity onto a day”, not “Activities can be dragged”.
No jargon — “block”, “activity”, “template” are the only product words.
Reassure about data: “All saved”, “Nothing was deleted”. Never blame.
24-hour times (9:00), UK spelling (“colour”).
